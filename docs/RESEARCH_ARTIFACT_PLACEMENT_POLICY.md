# Research Artifact Placement Policy

最終更新: 2026-07-25

## 目的

参考文献の読書メモ、理論草稿、投稿原稿を混在させず、原資料との対応とGit上の履歴を明確にする。

## 1. PDF読書メモ

論文、研究メモ、参考資料などのPDFを読み、行間、暗黙の仮定、証明の省略、既存研究との差を記録する場合、その読書メモは原PDFと同じフォルダに置く。

例:

```text
notes/2607星野さんアイデア/
  shadow_iv_latent_joint_aos_memo_ja_v6.pdf
  shadow_iv_latent_joint_aos_memo_ja_v6.tex
  AOS_THEORY_AUDIT_JA_2026-07-25.md
```

読書メモは原PDFとの対応が分かる名称とし、次を区別して記録する。

- PDFに明記された仮定・定理・証明
- 行間から必要と判断した追加条件
- 証明済みの結果
- 未証明または高水準仮定に置かれた結果
- 既存研究との重複
- 次稿で修正すべき点

読書メモは `notes/` または原PDFの保存先に置き、正式な新規投稿原稿の保存先にはしない。

## 2. 正式な新理論・投稿原稿

新しい理論原稿または投稿用原稿を正式に作り始める場合、日本語・英語を問わず、リポジトリ直下の既存ルート `build/` に新しいフォルダを作る。

フォルダ名には作成開始日の `YYMMDD` を必ず含める。

```text
build/YYMMDD_<project-name>/
```

例:

```text
build/260725_shadow_iv_latent_aos/
  README.md
  ja/
    main.tex
  en/
    main.tex
  references.bib
```

日本語稿だけから開始する場合でも、最初の正式原稿は同じ日付付きフォルダに置く。後から英語稿を作る場合は、同じ研究であれば同フォルダの `en/` に追加する。

別の中心定理、別の投稿先、または別研究として分離する場合は、開始日に応じて別の日付付きフォルダを作る。

## 3. ファイルの役割

各日付付き投稿フォルダの `README.md` に少なくとも次を記載する。

- 研究課題
- 中心定理
- 識別対象
- 現在の仮定
- 原資料・読書メモへの相対パス
- 日本語稿と英語稿の対応
- 証明済み、未証明、将来拡張の区別
- 投稿先と使用テンプレート

TeX、BibTeX、図表のソースをGitで管理する。生成PDFはリポジトリの `.gitignore` 方針に従い、必要な場合だけ別途管理方法を決める。

## 4. Git運用

- 作業前に実リポジトリと対象フォルダを確認する。
- ユーザーの未コミット変更を取り込まない。
- 読書メモ、理論修正、投稿書式変更を別々のatomic commitにする。
- 明示したファイルだけをstageする。
- 各atomic commit後にGitHubへpushし、`HEAD` と `origin/main` の一致を確認する。
- 既存資料は、明示的な依頼がない限り移動・改名・削除しない。

## 5. 本件への適用

`notes/2607星野さんアイデア/` にあるPDF、TeX、理論監査メモは、星野先生案を読むための原資料・読書記録として同じフォルダに維持する。

次にAnnals of Statisticsを目指す正式な理論原稿を作成する段階で、例えば

```text
build/YYMMDD_shadow_iv_latent_aos/
```

を新設し、まず日本語稿、その後英語稿を配置する。

現行83頁メモをそのまま投稿フォルダへ複製するのではなく、中心定理と証明範囲を確定した上で新規投稿稿として構成する。
