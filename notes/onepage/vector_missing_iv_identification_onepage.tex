\section{欠測IV法}
欠測値，選択，反実仮想の非観測はマイクロデータで頻繁に生じる。とくに非無作為欠測（MNAR）では，未観測値そのものが観測確率に影響するため，観測集団のみに基づく推論は一般に偏る。また，選択には影響するがアウトカムには直接影響しない通常の操作変数（IV）だけでは，アウトカム分布全体の点識別は困難である。

d'Haultfoeuille \cite{dhaultfoeuille2010} は，アウトカムを条件づけた後で操作変数と選択変数が独立になる欠測IV（missing IV / shadow variable 条件）により，欠測アウトカムの分布をノンパラメトリックに識別できることを示した。関連して，Zhao and Shao \cite{zhaoshao2015} は，スカラー応答のGLMで欠測機構を明示的に指定しない semiparametric な識別・推定を議論している。

このような欠測IVは，アウトカムについて排除制約を持つ通常のIVとは異なり，アウトカムに関連する変数をIVとして用いうる点に特徴がある。なお，ノンパラメトリックな点識別には，通常のIV問題と同様に完備性条件が重要となる。

\section{複数指標の同時欠測時への拡張}
本研究では，従来1次元で議論されていた従属変数を，ベクトル値へ拡張するための条件を整理する。

\(\D,\Y,\Z\) をそれぞれ，選択ダミー変数，従属変数，操作変数とする。\(\D,\Y\) は \(m\) 次元であり，
\[
\D=(D_1,\ldots,D_m)',\qquad
\Y=(Y_1,\ldots,Y_m)'
\]
とする。
以下の仮定を置く。

\begin{enumerate}[label={\textbf{仮定\arabic*.}},leftmargin=3.4em,itemsep=0pt,topsep=0pt,parsep=0pt,partopsep=0pt]
\item \(\D\) に関する指示変数を \(R=\1\{\D=\bm1\}\) とする。\(R=1\) のとき \((\Y,\Z)\) が観測され，この事象を完全ケースと呼ぶ。\(R=0\) のとき，\(\Y\) の少なくとも一部は観測されない。
\item 母集団における \(\Z\) の周辺分布 \(P(\Z)\) は識別されている。
\item \(\Y\) を条件づけると，\(R\) と \(\Z\) は条件付き独立である：
\(R\indep \Z\mid \Y\).
\item \(\Y\) は関数クラス \(B_{\Y}\) に関して \(\Z\) に対して完備である。すなわち，任意の \(g\in B_{\Y}\) について
\(\E\{g(\Y)\mid \Z\}=0\) a.s. ならば \(g(\Y)=0\) a.s. が成り立つ。
\item \(\pi(\bm y)=\Prb(R=1\mid \Y=\bm y)\) とし，\(\pi(\Y)>0\) a.s.
\end{enumerate}
\(B_{\Y}\) は \(g(\Y)\) が下有界かつ可積分となる関数のクラスである。仮定4は，\(\Z\) が \(\Y\) について十分豊かな情報を持つことを求める。

\noindent\textbf{命題1（条件付き独立性）.}
可測関数 \(\varphi,\psi\) が存在し，
誤差ベクトルを \(\eps=(\varepsilon_1,\ldots,\varepsilon_m)'\), \(\nuV=(\nu_1,\ldots,\nu_m)'\) とする。ただし，その分散共分散行列 \(\operatorname{Cov}(\eps)\), \(\operatorname{Cov}(\nuV)\) は非対角でもよい。このとき，
\par\vspace{-0.12\baselineskip}
\noindent\hfil{\footnotesize
\(\Y=\varphi(\Z,\eps),\quad
\D=\psi(\Y,\nuV),\quad
\nuV\indep(\Z,\eps)\)}\hfil\par
\vspace{-0.12\baselineskip}
を満たすならば，\(R\indep \Z\mid \Y\) が成立する。

\smallskip
\noindent\textbf{命題1の証明.}
固定した \((\bm y,\bm z,\bm d)\)（ただし \(\bm d\in\{0,1\}^m\)）に対して，誤差ベクトルの逆像集合を
\[
\mathcal A=\{u:\psi(\bm y,u)=\bm d\},\quad
\mathcal C=\{e:\varphi(\bm z,e)=\bm y\}
\]
とおく。このとき，
\par\vspace{0.08\baselineskip}
\noindent\hfil{\footnotesize
\(\begin{aligned}
\Prb(\D=\bm d\mid \Y=\bm y,\Z=\bm z)
&=\Prb(\nuV\in\mathcal A\mid \eps\in\mathcal C,\Z=\bm z)\\
&=\Prb(\nuV\in\mathcal A)\\
&=\Prb(\nuV\in\mathcal A\mid \Y=\bm y)\\
&=\Prb(\D=\bm d\mid\Y=\bm y).
\end{aligned}\)}\hfil\par
\vspace{0.02\baselineskip}
ただし，第二および第三の等号は \(\nuV\indep(\Z,\eps)\) と \(\Y=\varphi(\Z,\eps)\) による。最初と最後を比較すると，条件付き独立となる。任意の \(\bm d\) について成り立つため \(\D\indep\Z\mid\Y\) であり，\(R\) は \(\D\) の関数なので \(R\indep\Z\mid\Y\) も従う。
\endgroup

\medskip
\noindent\textbf{識別方針.}
仮定1--5の下では，
\[
\E\left\{\frac{R}{\pi(\Y)}\mid\Z\right\}=1
\]
という条件付きモーメント方程式が得られる。この方程式の解の一意性は，\(\Y\) の \(\Z\) に関する完備性に依存している。本発表では，その識別や \(\Y\) 全体の選択確率の回復のほか，本手法の応用可能性等について報告する。
