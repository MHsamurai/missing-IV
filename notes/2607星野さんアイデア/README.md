## 配置規則

本件PDFの追加読書メモは、原PDFとの対応が分かる形でこのフォルダに置く。

正式な新理論または投稿原稿はこのフォルダに作らず、

```text
build/YYMMDD_<project-name>/
```

に新設する。日本語稿と英語稿は同じ日付付き研究フォルダ内で管理する。

全体の規則は `docs/RESEARCH_ARTIFACT_PLACEMENT_POLICY.md` を参照する。
