# Presentation versioning

## ver1

`ver1/` is the frozen presentation snapshot for the 2026-07-18 interim presentation.
Do not edit files under this directory. The corresponding Git tag is
`presentation-ver1-2026-07-18`.

## ver2

`ver2/` is the active working copy initialized from `ver1/`. All subsequent
changes to the presentation source, manuscript, bibliography, figures, PDF,
and PPTX should be made under `ver2/`.

The files directly under `build/formal/presentation/` are retained for backward
compatibility and represent the pre-versioning formal deck at source commit
`550a2d7`.
