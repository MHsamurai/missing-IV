# resources

文献・講義資料を用途別に置きます。PDF等のバイナリ資料はGit追跡対象外です。
主要文献のファイル名と内容は`LITERATURE_INDEX.md`に記録します。

- `latent_multivariate/`: 潜在変数モデルと多次元MNARの関連文献
- `shadow variable/`: shadow variable、self-censoring、ICINの関連文献
- `missing/`: MNAR、欠測IV、semiparametric推定の基礎文献
- `data_fusion/`: data fusion / data combination関連文献
- `conference/`: 学会資料
- `layout/`: レイアウト参考資料
- `presentations/`: 発表資料
- `archive/`: 旧版・圧縮ファイル

論文PDFは原則として`Author_Year_Short_Title.pdf`の形式で命名します。複数著者は
識別に必要な範囲で姓を連結し、working paperと刊行版が異なる場合は版を明記します。
