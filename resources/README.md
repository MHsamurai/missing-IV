# resources

文献・講義資料を置きます。PDF等のバイナリ資料はGit追跡対象外です。

- `missing_iv/`: 欠測IV関連文献
- `data_fusion/`: data fusion / data combination 関連文献
- `course_notes/`: 講義ノート

文献は用途別に配置します。

- `missing_iv/`: 欠測IVに直接関係する文献
- `data_fusion/`: data fusion / data combination 関連文献
- `course_notes/`: 講義ノート
- `conference/`: 学会資料
- `layout/`: レイアウト参考資料
- `presentations/`: 発表資料
- `archive/`: 旧版・圧縮ファイル
